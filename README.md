# Connect 4

Решение kata [Connect 4](https://www.codewars.com/kata/586c0909c1923fdb89002031) (5 kyu) на Codewars.

## О задаче

Connect 4 («Четыре в ряд», «Captain's Mistress») — классическая игра для двух игроков на вертикальной сетке **7×6**. Фишки падают в выбранный столбец и занимают нижнюю свободную ячейку. Побеждает тот, кто первым выстроит **четыре** своих фишки подряд по горизонтали, вертикали или диагонали.

## Задание

Реализовать класс `Connect4` с методом `play(int $column)`, который принимает номер столбца (0–6 слева направо) и возвращает строку с результатом хода.

Пространство имён: `User\Codewars`. Исходник: `src/Connect4.php`.

## Правила

| Ситуация | Возвращаемая строка |
|----------|---------------------|
| Обычный ход (столбец не полон, победы нет) | `Player n has a turn` — **n** — игрок, который **только что** сходил (1 или 2) |
| Четыре фишки в ряд (горизонталь, вертикаль или диагональ) | `Player n wins!` — **n** — победивший игрок |
| Столбец уже заполнен (6 фишек) | `Column full!` — ход **не засчитывается**, следующий ход делает **тот же** игрок |
| Игра уже завершена победой | `Game has finished!` |

Дополнительно:

- Каждая новая игра начинается с **игрока 1**.
- Игроки ходят по очереди: 1 → 2 → 1 → …
- Столбцы нумеруются **0–6** слева направо.

## Примеры

```php
$game = new Connect4();
$game->play(0); // "Player 1 has a turn"
$game->play(0); // "Player 2 has a turn"

// Вертикальная победа в столбце 0
$game = new Connect4();
// ... семь ходов в столбцы 0 и 1 ...
$game->play(0); // "Player 1 wins!"

// Полный столбец
$game->play(4); // после 6 фишек в столбце 4:
$game->play(4); // "Column full!"

// Ход после победы
$game->play(4); // "Game has finished!"
```
